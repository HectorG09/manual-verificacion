# Manual de Verificación

Manual para verificar las obligaciones de transparencia de los sujetos obligados de Nayarit: qué revisar en cada fracción, cómo calificarla y cómo usar el Dictaminador VOT-LAIEN, con los casos reales de las verificaciones de 2026.

Es un solo archivo (`index.html`) que también se abre sin internet. Se genera en el proyecto VOT-LAIEN con `herramientas/manual_verificacion/construir_manual.py`; para actualizar esta página, se copia el HTML generado como `index.html`.
